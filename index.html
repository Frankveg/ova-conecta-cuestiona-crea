Cómo usar este OVA

Antes de entrar debes crear tu usuario o iniciar sesión con nombre de usuario y clave. Avanza en orden por los módulos. Tus respuestas y progreso se guardan únicamente en este navegador mediante almacenamiento local.

  • Se solicita un nombre de participante; evita introducir datos sensibles.
  • Puedes volver a cualquier módulo desde el menú.
  • El reto final se habilita cuando hayas recorrido los módulos 0 a 6.
  • Al finalizar puedes imprimir o guardar tu expediente como PDF.

Privacidad: este prototipo no envía datos a servidores externos.
